# Фаза 10 — Subgroup analysis / bias diagnostics

## Цель

Проверить, одинаково ли ведёт себя модель на разных подгруппах.

## Зависимости

Требуются завершённые:
- `Фаза 6`
- `Фаза 9`

## Что должен сделать Codex

1. Реализовать `scripts/evaluate_subgroups.py`.
2. Если доступны subgroup labels, посчитать метрики раздельно по:
   - gender
   - age buckets
   - ethnicity / race buckets
   - другим доступным группам

3. Для каждой подгруппы вычислить:
   - MAE
   - Spearman
   - mean prediction
   - residual statistics

4. Сохранить:
   - subgroup report;
   - таблицы;
   - визуализации разницы метрик.

## Критерии завершения

- subgroup metrics считаются автоматически;
- есть диагностический отчёт;
- зафиксированы потенциальные bias-проблемы.

## Команды проверки

```bash
python scripts/evaluate_subgroups.py
```

## Ограничения

- не добавлять subgroup labels как признаки в scorer без явной причины;
- это диагностическая, а не оптимизационная фаза.

## Что должен вернуть Codex после выполнения

1. таблицу метрик по подгруппам;
2. краткий вывод о смещениях;
3. рекомендации, надо ли дополнительно калибровать модель.
