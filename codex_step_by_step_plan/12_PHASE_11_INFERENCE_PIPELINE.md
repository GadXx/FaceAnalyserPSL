# Фаза 11 — Inference pipeline

## Цель

Собрать единый CLI pipeline для одного изображения:
- image -> face detection -> alignment -> features -> score

## Зависимости

Требуются завершённые:
- `Фаза 2`
- `Фаза 3`
- `Фаза 6`
- опционально `Фаза 8`

## Что должен сделать Codex

1. Реализовать `scripts/infer_image.py`.
2. На вход принимать:
   - путь к изображению;
   - путь к конфигу;
   - путь к модели.

3. Pipeline должен:
   - прочитать изображение;
   - найти лицо;
   - проверить quality gate;
   - сделать alignment;
   - извлечь признаки;
   - загрузить лучшую модель;
   - выдать score;
   - опционально выдать uncertainty.

4. Сформировать человекочитаемый результат:
   - JSON;
   - консольный вывод.

5. Сохранять inference log.

## Критерии завершения

- можно оценить одно изображение одной командой;
- pipeline не зависит от train-time кода сверх разумного;
- ошибки обрабатываются явно и читаемо.

## Команды проверки

```bash
python scripts/infer_image.py --image path/to/image.jpg
```

## Ограничения

- не делать веб-сервис на этом шаге;
- сначала CLI, потом API.

## Что должен вернуть Codex после выполнения

1. пример команды инференса;
2. пример JSON-ответа;
3. список обрабатываемых ошибок.
