# Фаза 9 — Robustness evaluation

## Цель

Проверить устойчивость лучшей модели к небольшим изменениям входного изображения.

## Зависимости

Требуется завершённая:
- `Фаза 6`
- желательно `Фаза 9` не зависит от `Фаза 7`/`Фаза 8`

## Что должен сделать Codex

1. Реализовать `scripts/evaluate_robustness.py`.
2. Для набора test-изображений применить мягкие преобразования:
   - небольшой crop shift;
   - brightness change;
   - contrast change;
   - jpeg compression;
   - small yaw-like perturbation, если реализуемо;
   - blur.

3. Для каждого изображения оценить:
   - исходный pred;
   - pred после perturbation;
   - абсолютное отклонение.

4. Построить:
   - summary table;
   - boxplot / histogram дрейфа предсказаний;
   - список самых нестабильных примеров.

## Критерии завершения

- robustness evaluation полностью автоматизирован;
- есть агрегированные показатели устойчивости;
- есть список failure cases.

## Команды проверки

```bash
python scripts/evaluate_robustness.py
```

## Ограничения

- не переобучать модель на augmented данных на этом шаге;
- только оценка устойчивости.

## Что должен вернуть Codex после выполнения

1. средний drift;
2. worst-case примеры;
3. вывод, насколько модель устойчива к nuisance-факторам.
